# Инструкция по созданию установочного .exe файла

## Что вы получите
После выполнения этих шагов у вас будет файл `TireShop.exe`, который можно раздавать пользователям. Им не нужно будет устанавливать Python или библиотеки - просто запустить .exe файл.

## Требования
- Windows компьютер
- Python 3.11 или новее (установлен)
- Интернет-соединение (для загрузки PyInstaller)

## Пошаговая инструкция

### Шаг 1: Скачайте проект
Убедитесь, что у вас есть все файлы проекта на компьютере.

### Шаг 2: Запустите сборку
1. Найдите файл **`build.bat`** в папке проекта
2. **Дважды кликните** на него
3. Дождитесь завершения (займёт 2-5 минут)

### Шаг 3: Готово!
После завершения сборки вы увидите:
```
========================================
  Build Complete!
========================================

The executable is located at:
  dist\TireShop.exe
```

### Где найти готовый файл
Готовый файл находится в папке: **`dist\TireShop.exe`**

## Как раздать пользователям

### Вариант 1: Простой (только .exe)
1. Скопируйте файл `dist\TireShop.exe`
2. Отправьте его пользователям
3. Пользователи запускают двойным кликом

**Важно:** При первом запуске создастся база данных `tire_shop.db` в той же папке, где находится .exe файл.

### Вариант 2: С папкой (рекомендуется)
Создайте ZIP-архив со следующими файлами:
```
TireShop/
├── TireShop.exe        (главный файл)
└── README_USER.txt     (инструкция для пользователей)
```

**Содержание README_USER.txt:**
```
СИСТЕМА УЧЁТА ШИНОМОНТАЖА
========================

УСТАНОВКА:
1. Распакуйте эту папку в любое место на компьютере
2. Запустите TireShop.exe

ПЕРВЫЙ ЗАПУСК:
- База данных создастся автоматически
- Стандартный PIN-код администратора: 0000

ВАЖНО:
- Все данные хранятся в файле tire_shop.db в этой же папке
- Чеки сохраняются в папку receipts/
- Для резервного копирования - скопируйте файл tire_shop.db

ПОДДЕРЖКА:
При проблемах обратитесь к администратору системы.
```

## Размер файла
Готовый .exe файл будет весить примерно **40-60 МБ** (включает Python и все библиотеки).

## Антивирусы
Некоторые антивирусы могут блокировать .exe файлы, созданные PyInstaller. Это нормально - просто добавьте файл в исключения антивируса.

## Обновление приложения
При изменении кода:
1. Запустите `build.bat` снова
2. Раздайте пользователям новый `TireShop.exe`
3. Пользователи заменяют старый файл новым (база данных сохранится)

## Автоматическое создание ярлыка на рабочем столе
Если хотите создать инсталлятор с автоматической установкой:
1. Установите Inno Setup: https://jrsoftware.org/isdl.php
2. Создайте скрипт установки (пример можно найти в документации Inno Setup)

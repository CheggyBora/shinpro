# Установка сервера: по шагам

Всё готово заранее. В день установки остаётся купить VPS и пройти
семь шагов — примерно час, из которых сорок минут ждёшь.

Нужны: VPS с Ubuntu 22.04 или 24.04, домен, ключ SMS-провайдера.

---

## 1. Домен смотрит на сервер

В панели регистратора заведите А-запись:

```
Тип: A    Имя: @    Значение: IP вашего сервера
Тип: A    Имя: www  Значение: IP вашего сервера
```

Подождите 10–20 минут и проверьте с любого компьютера:

```bash
ping ваш-домен.ру
```

Должен отвечать IP сервера. Пока не отвечает — сертификат не выпустится,
дальше идти бессмысленно.

## 2. Заходим на сервер

```bash
ssh root@IP-сервера
```

## 3. Копируем код

Если код в git:

```bash
apt-get update && apt-get install -y git
git clone АДРЕС-РЕПОЗИТОРИЯ /tmp/tire
cd /tmp/tire/server
```

Если репозитория нет — скопируйте папку `server` с компьютера:

```bash
# выполнять на своём компьютере, не на сервере
scp -r server root@IP-сервера:/tmp/tire-server
```

и на сервере: `cd /tmp/tire-server`

## 4. Одна команда

```bash
sudo bash deploy/install.sh ваш-домен.ру ваша@почта.ру
```

Она поставит PostgreSQL и Python, заведёт базу, создаст настройки со
свежими ключами, поднимет службу, настроит nginx, выпустит бесплатный
сертификат и включит ежедневные копии базы.

Почта нужна только для писем от центра сертификации о сроке действия.

## 5. Владелец дашборда

Впишите свой номер:

```bash
nano /opt/tire-server/.env
```

```
SERVER_OWNER_PHONE=+7 909 901-89-31
SERVER_OWNER_NAME=Ваше имя
```

Там же — ключ SMS-провайдера, когда он появится:

```
SERVER_SMS_PROVIDER=smsru
SERVER_SMS_API_KEY=ключ-из-личного-кабинета
```

Перезапустите:

```bash
systemctl restart tire-server
```

## 6. Заводим шиномонтаж

```bash
cd /opt/tire-server
sudo -u tire ./venv/bin/python manage.py add-account "Шиномонтаж «РИФ»"
```

Команда напечатает **ключ обмена**. Он показывается один раз —
скопируйте сразу.

Вторая точка, если она есть:

```bash
sudo -u tire ./venv/bin/python manage.py add-shop shinomontazh-rif "РИФ на Южной"
```

## 7. Связываем с цехом

В программе на компьютере шиномонтажа: **Настройки → Обмен с сервером**

```
Адрес:  https://ваш-домен.ру
Ключ:   тот, что напечатала команда
```

Нажмите «Проверить связь» — должно ответить, сколько клиентов на
сервере. Потом «Обменяться сейчас».

## 8. Бот для напоминаний клиентам

Клиентам напоминают двумя способами, и оба бесплатны.

**Уведомления в браузере уже работают** — `install.sh` выдал ключи сам, и
в кабинете появилась кнопка «Включить». Делать ничего не нужно. Но на
айфоне они включаются только после «Добавить на экран», а половина людей
туда не дойдёт, — поэтому нужен и бот.

**Бота подключаем руками**, шаг необязательный, но с ним клиенты
перестают забывать про запись.

1. В Telegram напишите [@BotFather](https://t.me/BotFather), команда
   `/newbot`. Он спросит название (`Шиномонтаж РИФ`) и имя-адрес
   (`rif_shiny_bot` — должно кончаться на `bot` и быть свободным).
2. Он ответит токеном вида `7123456789:AAE...`. Это пароль от бота —
   никому не показывайте.
3. Отдайте токен серверу:

```bash
cd /opt/tire-server
sudo -u tire ./venv/bin/python manage.py     bot shinomontazh-rif 7123456789:AAE... --url https://ваш-домен.ру
```

Слово после `bot` — короткое имя заказчика, его напечатала команда
`add-account` (видно и в `manage.py accounts`).

Проверить: откройте кабинет, нажмите «Подключить напоминания» — должен
открыться ваш бот, а после «Старт» прийти «Готово».

Рассылка идёт по таймеру, его поставил `install.sh`:

```bash
systemctl list-timers tire-notify      # когда следующий запуск
journalctl -u tire-notify -n 20        # что разослал
```

## Проверка

```bash
cd /opt/tire-server && sudo -u tire ./venv/bin/python manage.py check
```

Команда пройдёт по всему списку и скажет, чего не хватает.

Откройте в браузере:

- `https://ваш-домен.ру/z` — страница записи для клиентов
- `https://ваш-домен.ру/d` — дашборд владельца

В кабинете, если войти, появится карточка «Напоминать о записи»:
уведомления в браузере — всегда, Telegram — если подключён бот.

На телефоне страница записи предложит «Добавить на экран»: появится
ярлык, и кабинет будет открываться как приложение.

## Что дальше делать не нужно

Обновления, миграции базы и копии идут сами. Когда появятся правки
в коде:

```bash
bash /opt/tire-server/deploy/update.sh
```

Скрипт снимет копию базы, обновит зависимости, пройдёт миграции и
перезапустит службу. Если что-то пойдёт не так — скажет и оставит
старую версию работать.

---

## Если что-то не работает

| Что видно | Что смотреть |
|---|---|
| Страница не открывается | `systemctl status tire-server` и `journalctl -u tire-server -n 50` |
| Сертификат не выпустился | домен не смотрит на сервер — проверьте `ping`, потом `certbot --nginx -d ваш-домен.ру` |
| Цех не соединяется | ключ обмена скопирован не полностью, или в адресе нет `https://` |
| Напоминания не уходят | `journalctl -u tire-notify -n 30`; проверьте, что у бота задан `--url` с настоящим доменом |
| В кабинете нет кнопки «Включить» | в `.env` пусты `SERVER_PUSH_*`: выполните `manage.py push-keys`, впишите и перезапустите службу |
| Коды не приходят | `manage.py check` скажет, настроен ли провайдер |
| Дашборд не пускает | номер в `SERVER_OWNER_PHONE` записан не в том виде — годится любой, но телефон должен совпадать |

Копии базы лежат в `/var/backups/tire`, хранятся 30 дней. Чтобы они
уезжали ещё и наружу, допишите в `.env`:

```
SERVER_BACKUP_RSYNC=user@другой-сервер:/backups/tire/
```

Восстановление из копии:

```bash
gunzip -c /var/backups/tire/tire_ГГГГММДД_ЧЧММСС.sql.gz | \
    sudo -u postgres psql tire
```

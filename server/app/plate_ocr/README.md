# Чтение российских номеров

`cct_s_v2_ru.onnx` — модель fast-plate-ocr `cct-s-v2-global`, дообученная
26.10.2026 на 37,8 тыс. российских номеров (набор AY000554/Car_plate_OCR_dataset
на основе Nomeroff Net / AUTO.RIA, лицензия CC BY 4.0) с искажениями «как
вырезает детектор»: наклон, перспектива, рамка, надписи дилера.

Проверка на 2845 номерах, которых модель не видела: весь номер — 98,4%,
регион — 99,2%, трёхзначный регион — 99,1% (общая модель: 33,6% / 37,5% / 11,5%).

Модель принимает ровно одну картинку за вызов (64×128 RGB) — так её и
зовёт `app/services/plates.py`.

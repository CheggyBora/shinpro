========================================
  СИСТЕМА УЧЁТА ШИНОМОНТАЖА
========================================

БЫСТРЫЙ СТАРТ:
--------------
1. Запустите TireShop.exe двойным кликом
2. При первом запуске автоматически создастся база данных
3. Стандартный PIN-код администратора: 0000

ОСНОВНЫЕ ФУНКЦИИ:
-----------------
• Учёт сотрудников и смен
• Создание нарядов на обслуживание
• Расчёт зарплаты сотрудников
• История обслуживания автомобилей
• Хранение шин
• Печать чеков (PDF)

ВАЖНАЯ ИНФОРМАЦИЯ:
------------------
• Все данные хранятся в файле tire_shop.db (в той же папке)
• Чеки сохраняются в папку receipts/
• Для резервного копирования - скопируйте файл tire_shop.db

РЕЗЕРВНОЕ КОПИРОВАНИЕ:
----------------------
1. Закройте приложение
2. Скопируйте файл tire_shop.db в безопасное место
3. Для восстановления - замените файл tire_shop.db

СИСТЕМНЫЕ ТРЕБОВАНИЯ:
---------------------
• Windows 7 или новее
• 50 МБ свободного места на диске
• Разрешение экрана: минимум 1280x800

НАСТРОЙКИ:
----------
• Admin PIN (по умолчанию): 0000
• Изменить ставку сотрудника: выберите сотрудника → "Изменить ставку"
• Цены услуг: настраиваются через базу данных

РЕШЕНИЕ ПРОБЛЕМ:
----------------
• Если антивирус блокирует - добавьте TireShop.exe в исключения
• Если не запускается - убедитесь что файл не повреждён
• При потере данных - восстановите файл tire_shop.db из резервной копии

ПОДДЕРЖКА:
----------
При возникновении проблем обратитесь к администратору системы.

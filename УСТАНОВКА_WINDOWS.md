# 🔧 Установка и запуск на Windows

## Требования

- **Windows 10 или Windows 11**
- **Python 3.11 или новее** ([скачать здесь](https://www.python.org/downloads/))
- **Принтер** (для автоматической печати чеков)

---

## 📥 Шаг 1: Скачайте проект

1. Скачайте весь проект как ZIP-архив
2. Распакуйте архив в любую папку (например, `C:\TireShop\`)

---

## 🐍 Шаг 2: Установите Python

1. Скачайте Python 3.11 с официального сайта: https://www.python.org/downloads/
2. **ВАЖНО!** При установке обязательно поставьте галочку **"Add Python to PATH"**
3. Нажмите "Install Now"

### Проверка установки Python:

Откройте командную строку (Win+R → `cmd` → Enter) и введите:
```cmd
python --version
```

Должно показать: `Python 3.11.x` или новее

---

## 📦 Шаг 3: Установите библиотеки

1. Откройте командную строку (Win+R → `cmd` → Enter)
2. Перейдите в папку с проектом:
   ```cmd
   cd C:\TireShop
   ```
3. Установите библиотеки:
   ```cmd
   pip install -r requirements.txt
   ```

Подождите, пока все установится (обычно 1-2 минуты).

---

## ▶️ Шаг 4: Запустите приложение

### Способ 1: Двойной клик (самый простой)

Просто **дважды кликните** на файл `Запуск.bat`

### Способ 2: Через командную строку

```cmd
cd C:\TireShop
python main.py
```

---

## 🖨️ Печать чеков

После успешного запуска:

1. Создайте наряд (введите номер авто → "Создать наряд")
2. Добавьте услуги
3. Нажмите "💳 Пробить" → выберите способ оплаты
4. В диалоге появятся две кнопки:
   - **"🖨 Оплатить"** - автоматически отправит чек на принтер по умолчанию
   - **"👁 Просмотр"** - откроет PDF для просмотра перед печатью

---

## 📂 Где хранятся данные?

- **База данных**: `tire_shop.db` (в папке приложения)
- **Чеки**: папка `receipts/` (создаётся автоматически)

---

## 🆘 Возможные проблемы

### Ошибка: "Python is not recognized"

**Решение**: Python не добавлен в PATH. Переустановите Python с галочкой "Add Python to PATH".

### Ошибка при установке библиотек

**Решение**: Обновите pip:
```cmd
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Принтер не печатает

**Проверьте:**
1. Принтер включен и подключен к компьютеру
2. Принтер установлен как **принтер по умолчанию** в Windows
3. Используйте кнопку "👁 Просмотр" чтобы сначала проверить, что чек создался

## 🚀 Создание ярлыка на рабочем столе

1. Найдите файл `Запуск.bat`
2. Щелкните правой кнопкой → "Создать ярлык"
3. Перетащите ярлык на рабочий стол
4. Переименуйте ярлык в "Шиномонтаж"

Готово! Теперь можно запускать программу прямо с рабочего стола! 🎉

## ✅ Первый запуск

При первом запуске приложение автоматически:
1. Создаст базу данных `tire_shop.db`
2. Создаст папку `receipts/` для чеков
3. Заполнит прайс-лист услуг
4. Установит стандартный PIN-код администратора: **0000**

**Готово к работе!** 🎊

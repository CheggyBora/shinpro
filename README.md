# Система учёта шиномонтажа

Настольное приложение для управления шиномонтажом с современным интерфейсом.

## 🚀 Быстрый старт

### Требования
- Python 3.11 или новее
- Windows, Linux или macOS

### Установка

1. **Скачайте проект**
   ```bash
   git clone <url-репозитория>
   cd <название-папки>
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**

   **Windows:**
   - Дважды кликните на файл `Запуск.bat`
   - Или создайте ярлык на рабочем столе

   **Linux/Mac:**
   ```bash
   ./start.sh
   ```

## 📦 База данных

Приложение использует **SQLite** - локальную базу данных, которая создается автоматически при первом запуске.

- Файл базы данных: `tire_shop.db` (создается автоматически)
- Чеки сохраняются в папку `receipts/`
- Не требуется установка PostgreSQL

## ✨ Возможности

- 👥 Учет сотрудников и смен
- 📋 Создание нарядов на обслуживание
- 💰 Расчет зарплаты
- 🔍 История автомобилей
- 📦 Хранение шин
- 🧾 Автоматическая печать чеков (PDF)

## 🔧 Настройки

- **Admin PIN**: по умолчанию `0000` (для изменения ставок сотрудников)
- **Цены услуг**: настраиваются в базе данных

## 📝 Для разработчиков

### Структура проекта
```
├── models/           # Модели базы данных
├── services/         # Бизнес-логика
├── ui/              # Интерфейс приложения
├── receipts/        # Сгенерированные чеки
├── config.py        # Конфигурация БД
├── styles.py        # Стили интерфейса
└── main.py          # Точка входа
```

### Использование PostgreSQL (опционально)

Если хотите использовать PostgreSQL вместо SQLite:

1. Установите PostgreSQL
2. Создайте файл `.env`:
   ```
   DATABASE_URL=postgresql://пользователь:пароль@localhost/база_данных
   ```
3. Установите дополнительную зависимость:
   ```bash
   pip install psycopg2-binary
   ```

# Система учёта шиномонтажа

Настольное приложение для управления шиномонтажом с современным интерфейсом.

## 🚀 Быстрый старт

### Вариант 1: Готовый .exe файл (для конечных пользователей)
**Самый простой способ - не требует установки Python!**

1. Скачайте файл `TireShop.exe`
2. Запустите двойным кликом
3. Готово! База данных создастся автоматически

### Вариант 2: Запуск из исходного кода (для разработчиков)

**Требования:**
- Python 3.11 или новее
- Windows, Linux или macOS

**Установка:**

1. **Скачайте проект**
   ```bash
   git clone <url-репозитория>
   cd <название-папки>
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**

   **Windows:**
   - Дважды кликните на файл `Запуск.bat`
   - Или создайте ярлык на рабочем столе

   **Linux/Mac:**
   ```bash
   ./start.sh
   ```

### Вариант 3: Создание .exe файла для распространения

Если вы хотите создать установочный .exe файл:

1. Запустите `build.bat` на Windows компьютере
2. Готовый файл появится в `dist\TireShop.exe`
3. Раздайте этот файл пользователям

📖 **Подробная инструкция:** см. [BUILD_INSTRUCTIONS.md](BUILD_INSTRUCTIONS.md)

## 📦 База данных

Приложение использует **SQLite** - локальную базу данных, которая создается автоматически при первом запуске.

- Файл базы данных: `tire_shop.db` (создается автоматически)
- Чеки сохраняются в папку `receipts/`
- Не требуется установка PostgreSQL

## ✨ Возможности

- 👥 Учёт сотрудников и смен
- 📋 Наряды на обслуживание: скидки, расходники, время работы
- 💰 Расчёт зарплаты и её выдача — наличными или на карту, под PIN
- 📅 Запись клиентов: лента по постам и свободные окна
- 🔍 Клиенты, их машины, история визитов и рекомендации мастера
- 📦 Хранение шин: приём, выдача, акты
- 🧾 Печать чеков и актов (PDF), наклейки на комплекты
- 📊 Отчёты, выгрузка в Excel, сводка по смене в Telegram
- ☁️ Обмен с сервером: кабинет клиента и дашборд владельца

## 📱 Кабинет клиента и дашборд

Рядом с программой живёт сервер (папка `server/`). Через него работают
приложение клиента и дашборд владельца — выручка, наряды, зарплаты
с телефона. Цех при этом не зависит от интернета: без связи нельзя
только записать клиента, всё остальное работает как обычно.

Подробности — в [server/README.md](server/README.md).

## 🔧 Настройки

- **Admin PIN**: по умолчанию `0000` (для изменения ставок сотрудников)
- **Цены услуг**: настраиваются в базе данных

## 📝 Для разработчиков

### Структура проекта
```
├── models/          # Таблицы базы
├── services/        # Правила: наряды, зарплата, обмен, печать
├── ui/              # Экраны программы
├── server/          # Сервер: кабинет клиента и дашборд
├── tests/           # Проверки: python tests/run_all.py
├── receipts/        # Готовые чеки и акты
├── config.py        # База и доводка схемы при запуске
├── styles.py        # Оформление экранов
└── main.py          # Точка входа
```

### Тесты

```bash
python tests/run_all.py          # программа цеха
cd server && python tests/run_all.py   # сервер
```

Каждый набор запускается отдельным процессом на своей временной базе,
рабочую базу тесты не трогают.

### Использование PostgreSQL (опционально)

Если хотите использовать PostgreSQL вместо SQLite:

1. Установите PostgreSQL
2. Создайте файл `.env`:
   ```
   DATABASE_URL=postgresql://пользователь:пароль@localhost/база_данных
   ```
3. Установите дополнительную зависимость:
   ```bash
   pip install psycopg2-binary
   ```

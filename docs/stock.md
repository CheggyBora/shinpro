# Склад, расход по услугам и база зарплаты (26.10.2026)

Макет: https://claude.ai/artifact/1B6LjjBwkLRBxc9Bw2CsmB

## База зарплаты — отдельно для шиномонтажа и мойки

Настройки `salary_base_tire` и `salary_base_wash`:

- `revenue` — процент с итога строки услуги после всех скидок;
- `minus` — то же минус расходник строки (как было раньше у шиномонтажа).

По умолчанию оба `minus` — поведение не меняется, пока не переключат.
Товары в зарплату не входят ни в одном варианте.

## Склад — включается, по умолчанию выключен (`stock_enabled` = `0`)

Выключен — всё как раньше: расходник у услуги — сумма в рублях
(`Service.consumable_cost`), остатков нет.

Включён:

- **Позиция склада** (`stock_items`): направление (`tire`/`wash`), вид
  (`goods` — товар на продажу, `material` — уходит на услуги), название,
  единица (шт, л, кг, м, уп), остаток (может быть отрицательным),
  минимум, цена отпускная (обязательна), закупка (необязательна).
- **Товар** продаётся в наряде как позиция прайса: у него связанная
  услуга (`Service.is_goods`, `flat_price` = цена, направление то же).
- **Расход по услуге** (`service_materials`): материал и количество на
  одно выполнение. Расходник строки наряда в рублях = Σ количество ×
  отпускная цена материала (снимок при добавлении строки).
- **Пробили наряд** — списание: материалы услуг × количество строки,
  товары — их количество. **Возврат наряда** — обратно. Движения
  пишутся (`stock_moves`).
- **Мало** (остаток < минимума) — жёлтая отметка в программе и дашборде.
- **Минус** — допустим; при переходе в минус один раз — сообщение в
  Telegram тем, кому идёт сводка по смене.

## Обмен с сервером

`POST /sync/stock` (ключ точки):

```
→ {"enabled": true|false,
   "items": [{"uid", "name", "direction", "kind", "unit", "quantity",
              "min_quantity", "price", "purchase_price", "updated_at"}]}
← {"ok": true, "count": N}
```

Полный снимок: чего нет в списке — удалено. Цех шлёт его с обменом
живой очереди, когда снимок поменялся.

`GET /dashboard/stock?shop=&direction=all|tire|wash` (сотрудник) →
`{"enabled", "updated_at", "items": [... + "state": "neg"|"low"|"ok"]}`,
сначала минус, потом мало, потом по названию. В дашборде раздел «Склад»
виден, когда у точки склад включён.

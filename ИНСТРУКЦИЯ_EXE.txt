==========================================

ДЛЯ КОНЕЧНОГО ПОЛЬЗОВАТЕЛЯ (Windows 10/11):
============================================

✅ НЕ НУЖНО УСТАНАВЛИВАТЬ PYTHON!
✅ НЕ НУЖНО УСТАНАВЛИВАТЬ БИБЛИОТЕКИ!
✅ ПРОСТО СКАЧАЙТЕ И ЗАПУСТИТЕ!


УСТАНОВКА (2 шага):
===================

1. Скачайте папку "dist\TireShop" из архива
2. Распакуйте в любое место (например, C:\TireShop\)


ЗАПУСК:
=======

Дважды кликните на файл: TireShop.exe

Вот и всё! Программа запустится! 🎉


ЧТО БУДЕТ ПРИ ПЕРВОМ ЗАПУСКЕ:
==============================

Автоматически создадутся:
✓ База данных (tire_shop.db)
✓ Папка для чеков (receipts\)
✓ Прайс-лист услуг
✓ PIN администратора: 0000


КАК ПЕЧАТАТЬ ЧЕКИ:
==================

1. Создайте наряд:
   - Введите номер авто
   - Нажмите "Создать наряд"
   - Выберите диаметр колеса и тип транспорта

2. Добавьте услуги (кнопками или вручную)

3. Оплата:
   - Нажмите "💳 Пробить"
   - Выберите Наличные или Карта
   - Появится диалог с двумя кнопками:
   
     "🖨 Оплатить"  → Автоматическая печать на принтер
     "👁 Просмотр"  → Открыть PDF перед печатью


ГДЕ ХРАНЯТСЯ ДАННЫЕ:
====================

📁 В ПАПКЕ С ПРОГРАММОЙ:

tire_shop.db         - База данных (все наряды, клиенты, сотрудники)
receipts\            - Папка с чеками (PDF файлы)


ВАЖНО! РЕЗЕРВНАЯ КОПИЯ:
=======================

Регулярно копируйте файл "tire_shop.db" в безопасное место!
В нём хранятся ВСЕ данные программы.


ТРЕБОВАНИЯ:
===========

✓ Windows 10 или Windows 11
✓ Принтер (для печати чеков)
✓ ~200 МБ свободного места


ПОМОЩЬ:
=======

Проблема: Принтер не печатает
Решение: 
  - Проверьте, что принтер включен
  - Проверьте, что принтер установлен как "По умолчанию" в Windows
  - Используйте "👁 Просмотр" для проверки, что чек создался

Проблема: Не запускается программа
Решение:
  - Проверьте антивирус (добавьте в исключения)
  - Запустите от имени администратора

ДЛЯ РАЗРАБОТЧИКА (как собрать EXE):
====================================

ТРЕБОВАНИЯ ДЛЯ СБОРКИ:
- Python 3.11+
- Все библиотеки из requirements.txt


СБОРКА EXE (один клик):
========================

1. Откройте командную строку в папке проекта
2. Запустите: build.bat
3. Дождитесь окончания сборки
4. Готовый EXE будет в папке: dist\TireShop.exe


РУЧНАЯ СБОРКА:
==============

pip install pyinstaller
pip install -r requirements.txt
pyinstaller --clean tire_shop.spec


РЕЗУЛЬТАТ:
==========

dist\TireShop.exe  - Готовый исполняемый файл
(или dist\TireShop\ - папка со всеми файлами)

Можно распространять пользователям!

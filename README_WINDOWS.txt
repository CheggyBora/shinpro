  СИСТЕМА УЧЁТА ШИНОМОНТАЖА
  Версия для Windows 10/11
==========================================

БЫСТРЫЙ СТАРТ:
==============

1. Установите Python 3.11+ 
   https://www.python.org/downloads/
   ⚠️ Обязательно поставьте галочку "Add Python to PATH"!

2. Откройте командную строку в этой папке:
   Win+R → cmd → cd путь\к\папке

3. Установите библиотеки:
   pip install -r requirements.txt

4. Запустите приложение (один из способов):
   
   СПОСОБ 1 (проще): Дважды кликните на "Запуск.bat"
   
   СПОСОБ 2: В командной строке: python main.py


ПЕЧАТЬ ЧЕКОВ:
=============

После запуска:
1. Создайте наряд → добавьте услуги
2. Нажмите "💳 Пробить" → выберите Наличные/Карта
3. Появится диалог с кнопками:
   - "🖨 Оплатить" = автоматическая печать на принтер
   - "👁 Просмотр" = открыть PDF перед печатью


ГДЕ ХРАНЯТСЯ ДАННЫЕ:
====================

База данных: tire_shop.db (в папке приложения)
Чеки: папка receipts/ (создаётся автоматически)


ПЕРВЫЙ ЗАПУСК:
==============

При первом запуске автоматически:
✓ Создаётся база данных
✓ Загружается прайс-лист услуг
✓ Устанавливается PIN администратора: 0000

=======

Подробные инструкции: см. файл УСТАНОВКА_WINDOWS.md
